# Картинки гайда «Как узнать ID» для LuckyBear

Сюда нужно положить два файла:

- `lb_id_1.png` — экран LuckyBear со стрелкой на значок профиля в правом верхнем углу
- `lb_id_2.png` — экран профиля со стрелкой на ID под уровнем (вида `165ba529-04f5`)

Имена важны: на них ссылается `LUCKYBEAR_PROJECT_ID_GUIDE_STEPS` в
`src/project-account-id.js`. Пока файлов нет, гайд показывает только текст —
шаг с картинкой убирает себя сам, чтобы не оставлять значок битого изображения.

Размер как у остальных гайдов (`assets/pd_id_guide`), 150–700 КБ на файл.
